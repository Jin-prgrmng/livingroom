# LDK 10帖 3Dウォークスルー

新居のLDK（10帖）の家具配置を、身長165cmの目の高さから見て確かめるためのページ。`index.html` の1ファイルだけで動く。外部ライブラリもビルド手順も要らない。

## 公開の手順（GitHub Pages）

1. GitHubで新しいリポジトリを作る。可視性は Public にする。
2. `index.html` と `README.md` をアップロードしてコミットする。
3. リポジトリの Settings → Pages を開く。
4. Source で「Deploy from a branch」を選び、Branch を `main`、フォルダを `/ (root)` にして Save する。
5. 1分ほど待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される。スマートフォンからもそのURLで開ける。

Public リポジトリのGitHub Pagesは誰でも閲覧できる。URLを知られたくない範囲がある場合は、リポジトリ名に個人情報を含めない。

## 操作

- 画面をドラッグすると見回せる。
- 左下の十字ボタン、またはキーボードのW/A/S/Dと矢印キーで歩く。
- 右下の「全画面」で画面いっぱいに広がる。
- 上部のボタンで、入口・キッチン・ソファ・窓際・冷蔵庫前の5か所へ移動できる。

## 前提

寸法は間取り図から逆算した推定値であり、実測にもとづくものではない。10帖を約16平方メートルとして、室内を約5.5m×3.0mとしている。内装と家具の色や質感は雰囲気を示すためのもので、実物の再現ではない。
